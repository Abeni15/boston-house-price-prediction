# House Price Prediction using Linear Regression

## Project Overview

This project implements an end-to-end machine learning pipeline to predict housing prices using the Boston Housing dataset. The model is built using linear regression optimized with gradient descent and includes feature scaling, exploratory data analysis, and regularization analysis.

The objective is to understand how housing characteristics influence property value and demonstrate fundamental machine learning concepts such as regression modeling, optimization, and the bias–variance tradeoff.

---

## Dataset

The project uses the Boston Housing dataset, which contains 506 housing records and 13 features describing neighborhood and property characteristics.

Target variable:

* MEDV – Median value of owner-occupied homes.

---

## Machine Learning Pipeline

1. Problem Framing
2. Exploratory Data Analysis
3. Feature Engineering (Feature Scaling)
4. Linear Regression Implementation using Gradient Descent
5. Model Evaluation (MSE and R²)
6. Regularization and Bias–Variance Analysis
7. Model Interpretation

---

## Results

The model achieved an **R² score of approximately 0.65**, indicating that the model explains about **65% of the variance in housing prices**.

Key influential features include:

* RM (number of rooms)
* LSTAT (percentage of lower-income population)
* PTRATIO (pupil-teacher ratio)
